5 Principales Funcionalidades (Features)

Requerimiento Central de Plataforma

Para garantizar la trazabilidad con los roles establecidos, se detallan a continuación las cinco funcionalidades estructurales que el Usuario Final ejecuta en la plataforma, respaldadas por los servicios autónomos del Sistema e Inteligencia Artificial y supervisadas por la Administración:

FEATURE 01

Creación y Personalización de Hábitos

Permite al usuario diseñar nuevos hábitos parametrizando nombre, categoría temática (Salud, Estudio, Productividad), frecuencia programada (diaria, días específicos) y metas cuantitativas alcanzables.

Actores involucrados:
Usuario Final (Ejecuta) Sistema (Persiste)
FEATURE 02

Registro de Progreso Diario

Interacción ágil de micro-progreso donde el usuario marca el cumplimiento parcial o total de sus hábitos del día mediante retroalimentación táctil y actualización inmediata de estado.

Actores involucrados:
Usuario Final (Registra) Sistema (Valida / Timestamp)
FEATURE 03

Consulta de Historial y Rachas

Visualización analítica del desempeño acumulado, mapas de calor de constancia y cálculo automático de rachas consecutivas (streaks) para reforzar la motivación intrínseca.

Actores involucrados:
Usuario Final (Consulta) Backend (Calcula Métricas)
FEATURE 04

Recordatorios Inteligentes

El usuario configura sus ventanas horarias preferidas y el despachador del backend sincroniza notificaciones push locales y remotas en momentos estratégicos de la jornada.

Actores involucrados:
Usuario Final (Configura) Sistema (Programa / Dispara)
FEATURE 05

Recomendaciones Adaptativas por IA

El motor de inferencia heurística detecta patrones en los hábitos del usuario y genera sugerencias contextuales con puntuación de confianza, permitiendo al usuario aceptarlas con un toque o descartarlas.

Actores involucrados:
Sistema / IA (Infiere) Usuario Final (Decide) Admin (Audita Modelo)
