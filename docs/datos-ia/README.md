# Datos e inteligencia artificial

Contendrá modelos de datos, diccionarios, procedencia y calidad de datos, telemetría, consentimiento biométrico y documentación de modelos de analítica o IA.

La documentación deberá incluir límites de uso, versiones, métricas, sesgos conocidos y criterios para abstenerse de generar resultados. Se usarán ejemplos sintéticos o anonimizados.
