# Documentación de Quantify Core

Este directorio reúne la documentación funcional y técnica del proyecto, además de los entregables de las prácticas académicas.

## Estructura

| Sección | Contenido |
|---|---|
| `requerimientos/` | Requisitos funcionales y no funcionales, historias de usuario y criterios de aceptación. |
| `arquitectura/` | Arquitectura del sistema, componentes, diagramas y decisiones técnicas. |
| `diseno/` | Diseño de experiencia e interfaz, modelos de datos y diagramas de dominio. |
| `api/` | Contratos de API, endpoints, autenticación y ejemplos de integración. |
| `guias/` | Manuales de usuario y guías para contribuir al proyecto. |
| `despliegue/` | Configuración de entornos, instalación y publicación. |
| `Practica04/` | Material correspondiente a la Práctica 04. |
| `Practica05/` | Material correspondiente a la Práctica 05. |

Las secciones temáticas se irán incorporando conforme avance la definición del sistema. Los documentos de prácticas existentes se conservan en sus directorios actuales.
