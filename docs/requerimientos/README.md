# Requerimientos

Esta sección reunirá los requisitos funcionales y no funcionales de Quantify Core, sus historias de usuario, criterios de aceptación, reglas de negocio y prioridades.

Cada requisito deberá contar con identificador, estado, fuente y relación con las pruebas o entregas que lo validen. Las decisiones aún no aprobadas se marcarán como propuestas.
