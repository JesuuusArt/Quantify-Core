# Aplicación móvil

Aplicación multiplataforma propuesta con Flutter y Dart para Android e iOS. Contendrá la experiencia personal de hábitos, el seguimiento diario, las preferencias y la sincronización con la API.

La documentación futura incluirá navegación, gestión de estado, permisos, funcionamiento sin conexión, notificaciones, configuración y comandos de ejecución. La aplicación aún no está implementada en esta carpeta.
