# Aplicación web

Cliente web propuesto con React, TypeScript y Vite, con capacidades PWA. Contendrá las vistas de seguimiento, métricas y administración que correspondan al alcance aprobado.

Cuando se inicie su implementación, aquí se documentarán la estructura de páginas y componentes, accesibilidad, configuración local, variables de entorno y comandos de desarrollo y compilación. La aplicación aún no está implementada en esta carpeta.
