# Integración Wear OS

Esta carpeta alojará la integración por fases con dispositivos Wear OS para recopilar únicamente las señales que el usuario autorice.

Se documentarán los dispositivos compatibles, permisos, tipos y frecuencia de datos, sincronización, consumo energético, revocación del consentimiento y pruebas. El SDK y el protocolo de comunicación quedan pendientes de una decisión técnica.
