# Aplicaciones cliente

Esta carpeta agrupa las aplicaciones que usan las personas para interactuar con Quantify Core. Cada subcarpeta documenta el cliente previsto; el código se añadirá cuando se definan sus requisitos, responsables y entorno de ejecución.

- [`web/`](web/README.md): cliente web y PWA.
- [`mobile/`](mobile/README.md): aplicación móvil multiplataforma.
- [`wear/`](wear/README.md): integración progresiva con Wear OS.
