# Pruebas

La documentación futura especificará cómo ejecutar cada conjunto, datos de prueba, requisitos del entorno, resultados esperados y relación con los criterios de aceptación. Las pruebas unitarias podrán residir junto al código de cada componente si se adopta esa convención.
