# Infraestructura

Documenta los recursos necesarios para ejecutar, observar y desplegar los componentes de Quantify Core.

- [`docker/`](docker/README.md): imágenes y entorno local reproducible.
- [`observability/`](observability/README.md): métricas, trazas, logs y alertas.
- [`deployment/`](deployment/README.md): configuración de publicación por ambiente.

Las configuraciones se incorporarán cuando se decidan los servicios y proveedores de despliegue.
