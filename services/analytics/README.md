# Analítica e inteligencia artificial

Servicio propuesto con Python y FastAPI para preparar indicadores, ejecutar modelos o reglas estadísticas y producir recomendaciones explicables.

Aquí se documentarán datos de entrada autorizados, características, versiones de modelos, métricas, límites, criterios para abstenerse y endpoints internos. No se emitirán diagnósticos médicos; el uso de datos sensibles requiere consentimiento y controles definidos.
