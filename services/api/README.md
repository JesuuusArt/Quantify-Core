# API principal

Servicio de negocio propuesto con Node.js, TypeScript y NestJS. Expondrá endpoints REST, aplicará las reglas del dominio y coordinará identidad, persistencia y tareas asíncronas.

La documentación de implementación deberá cubrir módulos, autenticación y autorización, validación, manejo de errores, migraciones, configuración local y pruebas. Los contratos compartidos se alojarán en `packages/contracts/`.
