# Procesos asíncronos

Contendrá trabajos que no deben bloquear una solicitud del usuario, como el cálculo de agregados, la programación de recordatorios, el procesamiento de eventos y la coordinación de recomendaciones.

La implementación deberá documentar colas, reintentos, idempotencia, manejo de fallos, programación y observabilidad. La tecnología de colas queda pendiente de validación.
